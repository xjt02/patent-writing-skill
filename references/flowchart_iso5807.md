## 待补充内容

### 基本符号

| 符号 | 名称 | 用途 |
|---|---|---|
| 圆角矩形 | 起止框 | 流程图起点和终点 |
| 矩形 | 处理框 | 一般处理步骤 |
| 菱形 | 判断框 | 条件判断（是/否） |
| 平行四边形 | 输入/输出框 | 数据输入或输出 |
| 箭头 | 连接线 | 流程方向 |
| 子程序框 | 子程序 | 调用其他流程 |

### 编号规则
- 每个符号内文字不超过10个汉字
- 判断框有两个出口（是/否）
- 连接线不应交叉

### 与 visio-scientific-flowchart 的对应

- `terminal_start` → 起止框（圆角矩形）
- `process` → 处理框（矩形）
- `decision` → 判断框（菱形）
- `data` → 输入/输出框（平行四边形）
- `connector` → 连接点（圆圈）
